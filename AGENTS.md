# Project Agent Instructions

This project is a Vite React TypeScript frontend. When changing frontend code,
follow the conventions in [docs/frontend-development.md](docs/frontend-development.md).

## Local Priorities

- Keep the app frontend-only unless a task explicitly asks for backend behavior.
- Prefer small, typed React components composed from shadcn/ui primitives.
- Use Tailwind CSS utilities for styling and keep custom CSS minimal.
- Use arrow functions for React components, hooks, utilities, callbacks, and
  exported helpers.
- Keep files colocated by component or feature so behavior, types, and helpers
  stay easy to discover.

## Documentation

When a task depends on current library behavior, check current docs before
implementation. This especially applies to Vite, React, TypeScript, Tailwind CSS,
and shadcn/ui.
